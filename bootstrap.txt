# NameSweep — WHOIS marker bootstrap
#
# While config/tlds.php has EMPTY marker arrays for a TLD, the WhoisClient
# reads markers from this file instead. Fill in the marker strings after
# running a one-off WHOIS test on the VPS, then commit this file.
#
# How to fill it in:
#   1. On the VPS, run a WHOIS query for a KNOWN-REGISTERED domain and a
#      KNOWN-AVAILABLE domain on each of .do and .ht, e.g.:
#        printf 'example.do\r\n' | nc whois.nic.do 43
#        printf 'definitely-not-registered-xyz.do\r\n' | nc whois.nic.do 43
#   2. Look at the two responses. Pick a short substring that ONLY appears in
#      the available response (e.g. "No match for", "NOT FOUND", "no entries
#      found") and one that ONLY appears in the registered response
#      (e.g. "Domain Name:", "Registrar:", "Creation Date:").
#   3. Uncomment and set the marker lines below. You can repeat a key to add
#      more markers for the same status.
#
# Format per TLD section:
#   available_marker  = <substring seen only in responses for unregistered names>
#   registered_marker = <substring seen only in responses for registered names>
#   parked_marker     = <optional>
#   for_sale_marker   = <optional>
#
# Until markers are filled in here (and in config/tlds.php), .do and .ht
# checks return `uncertain` and log the raw WHOIS response for debugging.
